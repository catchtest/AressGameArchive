# 亞里斯王物語 遊戲資料站

**The Story of King Aress** 中文遊戲資料與攻略整理，收錄《亞里斯王物語》的劇情、角色、敵人、裝備、道具、魔法、職系、種族、商店、地圖與戰鬥資訊。

瀏覽網站：**[亞里斯王物語 遊戲資料站](https://catchtest.github.io/AressGameArchive/)**

## 網站內容

- **流程與劇情**：主線攻略、地點對話、出現條件、角色加入與離隊、事件獎勵。
- **地圖與戰鬥**：各地位置、城鎮設施、戰場配置、敵方組成與勝利條件。
- **角色與敵人**：能力值、裝備、抗性、弱點、可使用或習得的魔法，以及相關劇情與戰場。
- **裝備、道具與魔法**：效果、能力加成、屬性、適用職系、價格、取得來源與施法台詞。
- **職系與種族**：角色轉職、等級稱號、移動力、升級屬性加成與經驗需求。
- **商店與公式**：販售商品、抽獎獎品與機率，以及能力、命中、會心、戰鬥傷害等計算方式。

支援分類搜尋、表格排序、詳細資料側欄、劇情逐段播放與戰場縮放。點擊相關角色、物品或地點，可查看對應資料。

資料依遊戲原始檔案整理，保留像素圖像與原文內容，方便查閱、比較與遊玩時使用。
