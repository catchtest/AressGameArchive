# 亞里斯王物語 遊戲資料站

**アレス王の物語 / The Story of King Aress**

這是《亞里斯王物語》的靜態遊戲資料站，整理 NEC PC-9801 原版與繁體中文版中的遊戲內容。

[開啟資料站](https://catchtest.github.io/AressGameArchive/)

## 收錄內容

- 主線劇情、地點劇情與出現條件
- 世界地圖、城鎮設施與商店抽獎
- 戰場配置、角色與敵人資料
- 裝備、道具、魔法、職系與種族
- 能力計算、命中率、物理傷害及屬性規則

## 資料來源

網站內容由遊戲資料與原始執行檔解析產生。無法由程式明確證實的內容會標示為尚未確認，避免將推測寫成遊戲設定。

## 建置程式

本版本庫存放可直接由 GitHub Pages 發布的網站成品。擷取與建置程式位於 [AressGameArchiveBuilder](https://github.com/catchtest/AressGameArchiveBuilder)。

`index.html` 與 `assets/` 由建置程式產生；本 README 會在重新建置時保留。
